# BUG HUNTER

基礎プログラミングII 前期理解度試験の対策サイト。
C言語のバグを撃ち抜くゲームで、構造体・動的メモリ・ファイル操作・GitHub を復習します。

**▶ [遊ぶ](https://goldfishstar0055.github.io/kisopuro-test/)**

---

## 4つのモード

| モード | 内容 |
|---|---|
| ⚔️ コードバトル | 選択肢ではなく**自分の手で書く**。37問のプールから10問を抽選、3体の敵と戦うRPG形式。第2問（穴埋め20点）の直接対策 |
| 📖 授業の復習 | 第2回〜第12回を章ごとに読み進める。解説30枚＋演習30問。**区切りごとに必ず演習が入る**ので、わかったつもりで先に進めない |
| 🎯 バグハンター | コードの中から壊れている1行をクリックで撃ち抜く。全18問・残機3。試験の第3問（30点）と同じ作業 |
| ⏱ タイムアタック | 90秒で何問答えられるか。連続正解でスコア倍率アップ、誤答は3秒ペナルティ。全40問からシャッフル |

はじめてなら「授業の復習」から。読んで理解したらコードバトルで書く力を、
バグハンターで見抜く力を、タイムアタックで速さを鍛えます。

ホーム画面に**勉強した時間・取り組んだ回数・総合正解率**、そして
**みんなの中での偏差値**が表示されます。
ハイスコアと章のクリア状況もブラウザに保存されます。

## 偏差値

順位表は出しません。「誰が1位か」ではなく「自分がだいたいどのあたりか」だけがわかります。

- 3モードのベストスコアを各100点に正規化した合計（300点満点）で算出
- 偏差値50がちょうど真ん中
- 参加者が5人未満のあいだは表示されない（数字が暴れるため）
- 送信するのは点数と正解数だけ。名前・端末情報・間違えた問題は送りません
- サーバーは Google Apps Script + スプレッドシート（`12_偏差値サーバー_AppsScript.gs`）
- `index.html` の `const API = ""` にウェブアプリURLを貼ると有効になります。
  空のままなら偏差値の表示は出ず、それ以外は通常どおり動きます

## コードバトル

キーボードで実際にコードを打ち込むモードです。

- ▢ を埋める問題（29問）と、1行まるごと書く問題（8問）
- 空白の数、末尾の `;`、全角入力のゆれは自動で吸収されます
- 正解で敵にダメージ、不正解で自分の HP が減る。HP は5
- 敵は3体（セグフォ・スライム → メモリリーク・ゴースト → ダングリング・ドラゴン）

## 出題範囲

第2〜13回（構造体・GitHub・malloc/free・ファイル操作）

- **動的メモリ** … malloc / free / realloc / メモリリーク・二重free・ダングリング
- **ファイル操作** … fopen の3モード / NULLチェック / fprintf / fgets + sscanf / fclose

## 操作

| キー | 動作 |
|---|---|
| `1` 〜 `4` | 選択肢を選ぶ（授業の復習・タイムアタック） |
| `Enter` | 次へ進む（授業の復習・バグハンター） |

マウス操作だけでも遊べます。

## 技術メモ

- 単一の `index.html`（HTML + CSS + JavaScript）。ビルド不要
- 外部依存はフォント（Google Fonts の DotGothic16）のみ
- ハイスコア・章の進捗・学習記録は `localStorage` に保存
- 敵キャラはドット絵パターンから SVG を生成（画像ファイルなし）
- パレットは [Sweetie 16](https://lospec.com/palette-list/sweetie-16)
